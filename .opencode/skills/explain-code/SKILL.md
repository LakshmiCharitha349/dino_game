# Explain Code

1. Read the relevant code before explaining it.
2. Identify the main purpose of the code.
3. Explain execution flow in small, ordered steps.
4. Explain unfamiliar syntax only when necessary.
5. Use a small example to illustrate important behavior.
6. Do not modify files.
7. End with one short practical exercise.
8. Keep each response focused on one concept.
